About the Data

The Health Care Data Set (20+ Tables), is a publicly available relational dataset on Kaggle. Patients, appointments, treatments, payments, staff, and supplies are stored separately and connected through shared reference numbers. It has at least 20 interlinked tables, and with more than 200 columns across all tables.

The dataset is organized as 22 items: five folders (diagnosis, inventory, payments, treatment-related records, and vendor payments) containing 2, 98, 3, 5, and 2 CSV files respectively, and seventeen standalone CSV files. The inventory folder holds most of the files, which suggests that stock movement is recorded in fine detail.

ReferenceAhmed, M. (2025, November). Health Care Data Set ( 20+ tables ). Kaggledatasets. https://www.kaggle.com/datasets/moid1234/health-care-data-set-20-tables
